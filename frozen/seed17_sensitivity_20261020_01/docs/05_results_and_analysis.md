# 本轮训练、评估与结果解释

## 1. 实验过程

保留批次 `wide_compute1000_w5_cutoff_20261020_01`。该轮在中心500×500m用户区、1000cycles/bit、奖励时延权重5的参数下，增加“累计能耗达到12000J后下槽关闭计算服务、继续飞行”的规则。8组环境一致；6个学习组各从零训练1000episode/60000步，训练与场景主种子固定1。

每3000步在episode 20000–20002验证，按“全组电池/期限可行优先，其次回报，最后J”保存best；不是按最终开发集重新挑模型。训练完分别用原best和last评估episode 30000–30009。之后固定原best，增加种子1–20、每种子episode 30000一次的评估，未重新训练、未据新结果换checkpoint。

| 学习组 | 所选best训练步数 |
|---|---:|
| Pure PPO | 24000 |
| Hybrid PPO | 51000 |
| Hybrid SAC | 33000 |
| Hybrid DDPG | 3000 |
| Hybrid PPO AR-adaptive | 18000 |
| Hybrid PPO AR=0.5 | 12000 |

最后模型统一为60000步。best较早不等于方法已全局收敛，也可能表示后续探索、策略更新或3场景选模波动；应结合validation.csv、episode曲线、KL/动作尺度及last结果判断。

## 4. 可以得出的结论

- 固定本次模型和20场景，AR=0.5综合更稳：较原混合PPO，总能量约低3.14%，平均回报提高20.91，能量可行20/20；J约低0.52%。自适应AR的J最低，但总能量更高，能量可行19/20。
- 原混合PPO、自适应AR与AR=0.5的J差异不到1%；回报优势很大一部分来自碰撞/越界及能耗罚项改善，不能全部说成时延降低。
- 两种贪心及SAC/DDPG仍普遍超预算。计算停服不能消除继续飞行的推进能耗，所以停服后能量可行率仍可能为0。需同时看每机能量、停服帧和回报分解。
- 原混合PPO与自适应AR各有1个20种子场景在最后槽结束才跨预算，故能量可行19/20而停服帧比例仍为0。
- Pure PPO的能量可行与服务质量分离：J场景中位数6.1117、最差种子18为43.1679。少数任务进入极差卫星链路造成时延长尾，不能用68%左右按期率掩盖失败任务。

此前针对Pure PPO的只读诊断还发现：固定动作开启/关闭停服重放时，原10场景评估结果相同；新训练探索中却曾触发停服，改变后续学习。原10场景best中，少量极慢任务主导平均J，且best/last表现可相反。因此不能把新best的时延变差直接解释为“停服让能量可行模型变慢”，也不能仅凭平均回报曲线变平宣称稳定收敛。

## 5. 当前结论边界

训练只有seed1，20种子仅检验固定模型对场景的泛化，未衡量重新训练的不确定性。3个选模场景很少，开发集经历过多轮研究，不能当未使用的最终测试。原best/last均保留，负结果不删。

没有保证所有学习方法已收敛或改进PPO普遍最优；关联有限扫描也不保证每槽全局最优。旋翼模型不计额外加速/转弯能量，卫星为有效城市块信道代理。下一轮调参应先固定评价协议、看回报分解及长尾，再评估改动，而不是改弱基线或按结果挑场景。
