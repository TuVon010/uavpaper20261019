# 方法与十组实验

使用单个集中式控制器统一观察20用户和3架UAV。无需把三架机强行拆成多智能体。每组学习方法都使用相同环境步预算与外生随机场景。

| ID | 轨迹 | 卸载/资源 | 价值或策略改进 |
|---|---|---|---|
| baseline_priority_greedy | 加权速率贪心 | 优先级贪心 | 无训练 |
| baseline_greedy_solver | 同一加权速率贪心 | 我们的求解器 | 无训练 |
| pure_ppo | PPO | PPO | 原PPO |
| pure_sac | SAC | SAC | 原SAC |
| pure_ddpg | DDPG | DDPG | 原DDPG |
| pure_ppo_ar_adaptive | 改进PPO | 同一改进PPO | 自适应AR＋学习当前/延续价值 |
| pure_ppo_ar05 | 改进PPO | 同一改进PPO | AR=.5＋学习当前/延续价值 |
| hybrid_ppo | 原PPO | 求解器 | 原标量Critic |
| hybrid_ppo_ar_adaptive | 改进PPO | 求解器 | 自适应AR＋已知当前/延续价值 |
| hybrid_ppo_ar05 | 改进PPO | 求解器 | AR=.5＋已知当前/延续价值 |

两种混合改进组另有可选降噪、Actor学习率衰减。默认都开，其余组都关。两种改进是完整组合对比，不能把其收益单独归因于AR或Critic，单因素归因应另做消融。

## 基线的可执行定义

原描述“搜索所有方向”“扣减剩余资源”需要离散精度与每次预留规则才可执行。本版把这些规则固定、公开：

1. 每架UAV依次搜索72个方向、5个速度层（含悬停），再做两轮局部细化。用槽首可观测CSI按距离平方比预测候选位置的加权总速率，选最优可行速度。**不读取累计能量、剩余电池或能量罚项**；速率数值相同时以较小速度打破平局，无能量目标。
2. 三机速度经过同一安全处理。它影响下一槽，本槽仍以槽首链路服务。
3. 优先级贪心按 w=1/d 降序。尚有r个任务、4个远端节点时，对每个候选提供该节点剩余带宽/CPU的 1/ceil(r/4)；本地CPU独享。
4. 用这些资源估算本地/三机/卫星时延，从期限可行候选选最小时延；无可行候选时保留最小时延结果并记录超期。立即扣减所选节点资源。
5. 分配完，将已使用节点的剩余资源按原预留份额返还给其用户，避免白白闲置；不重新选择节点、不调用KKT。

第二个基线只替换步骤3–5为我们求解器。因此两组可观察资源优化收益；不同关联历史不会作为贪心轨迹的输入。能量使用仍真实统计，超预算不隐藏。

## 混合求解器：关联博弈＋凸资源分配

固定当前几何/信道，节点j给定用户集合 S_j，求

\[
\min_{b_i,f_i>0}\sum_{i\in S_j}w_i
\left[D_i/R_{ij}(b_i)+C_i/f_i+\delta_{ij}\right],
\quad \sum b_i\le B_j,\ \sum f_i\le F_j,\ T_i\le d_i.
\]

固定功率下速率关于b是凹函数，正速率倒数与C/f为凸函数，目标与期限约束均凸。定义截止时间乘子 μ_i≥0，q_i=w_i+μ_i，则

\[
f_i^*=F_j\frac{\sqrt{q_iC_i}}{\sum_{k\in S_j}\sqrt{q_kC_k}},\qquad
q_i\frac{\partial[D_i/R_{ij}(b_i)]}{\partial b_i}+\lambda_b=0.
\]

无活动期限约束时 μ=0，CPU恢复 √(wC) 闭式。带宽没有香农公式下的通用显式闭式：代码用单调KKT关系和等式约束Newton解；活动期限乘子通过活动集/对偶Newton协调。数值未获证书时保留凸原问题后备求解，检查可行性、KKT/对偶间隙；不会把失败当最优。具体见 `resources.py`。

对关联a定义共同成本势函数 Φ(a)=固定a时最优资源下的∑wT。用户单边迁移时，重算受影响资源组，只有候选可行且证书确认整体成本至少下降ε才接受。上一槽可行解及本地起步修复产生初值；修复有有界双用户重定位，不遍历5^20种关联。

严格下降＋有限关联空间意味着无限制完整扫描可有限终止于ε单边稳定点；这不是全局最优证明。本版最多5轮，达到上限、未解决数值候选或修复失败都报告，**不能无条件宣称每槽已到Nash均衡**。缓存节点集合、下界剪枝减少重复凸求解。单次关联扫描至多约N(K−1)个迁移候选，K=5，每候选需相关节点凸求解；内层迭代和修复费用也要计入实际时延。

## 纯强化学习接口

纯RL动作146维：6个速度分量、20×5个节点偏好、20个带宽偏好、20个CPU偏好。

速度分量由tanh映射后乘v_max，再按欧氏范数限速。节点偏好形成分类分布，每任务整体选一个位置；资源偏好在对应节点关联用户内softmax归一化，满足资源池总量。路由采样使用独立键控场景随机流，所有方法同episode/frame使用同一随机数。

纯RL全过程不调用关联/KKT求解器，包括改进组。确定性评估指连续Actor输出条件均值，底层类别路由仍按相同声明的键控采样执行；不是悄悄改成argmax。

## AR策略与两类延续价值

AR只作用于前6维速度的未压缩高斯变量，卸载/资源维度仍由原策略输出：

\[
z_t=\rho_tz_{t-1}+(1-\rho_t)\mu_\theta(s_t)
+\sqrt{1-\rho_t^2}\,\sigma_\theta\epsilon_t,\quad a_t=\tanh z_t.
\]

上一速度潜变量显式加入状态，回合初清零；固定组ρ=.5。自适应组每架机一个ρ_t=.9·sigmoid(h_θ(s_t))，初始ρ=.8。上式σ包含当前启用的降噪乘数κ；乘数在整个rollout内固定。PPO的旧/新似然都使用同一条件分布和原始高斯样本，不对已投影动作捏造密度。

混合组的当前任务成本在速度选择前已由槽首求解器确定，可缓存 c_t=−J_t。延迟价值写为 c_t+U(s_t)，罚项价值独立为V_p；最后服务槽U强制0。原混合PPO也取得相同的上一速度和当前成本信息，区别在策略/价值结构。

纯RL的当前成本还取决于卸载与资源动作，不能读取求解器结果当c_t。按用户确认，本版学习三个内部PopArt头：W(s_t)估计当前期望−J_t、U(s_t)估计未来延迟回报、V_p(s_t)估计罚项。对外价值分量仍为[W+U,V_p]，最后槽U=0。目标为[当前延迟奖励，延迟GAE回报−当前延迟奖励，罚项GAE回报]。Actor/Critic都不读取未来任务表，也不借用混合组当前实际成本。

纯RL的三个内部头各有独立PopArt均值/标准差，价值MSE平均三个归一化头的误差。对外仍输出[W+U,V_p]；延迟和罚项的优势先在物理奖励单位相加，再对总优势做一次标准化，绝不分别按各头方差重加权Actor目标。可选价值裁剪也作用于这三个内部头。

PopArt只调整训练尺度并补偿输出参数，实际奖励和物理价值单位保持不变。γ=1对应固定60帧等权目标；GAE不是收敛证明。
