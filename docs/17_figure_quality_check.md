# 图表核验记录

本次仅整理已完成结果，不调参数、不新训练、不重选best。绘图后核验以下内容：

1. 数据范围为seed17批次18case、144job、108000个训练episode、252次评估、2520个评估episode。原始数据约17.1GB，由既有归档清单逐文件校验。
2. 训练曲线浅线为原始值，粗线为向后25轮均值；Pure PPO的异常长尾全部保留。全方法线性图、全方法symlog副图和明确标注的混合方法视图同时保存。
3. 每张指标图的来源CSV直接列出各评估episode的3指标。best/last严格分离；10场景均值和episode30000单场景分离。误差线是min–max而不是置信区间。
4. 扫描best/last共320条数据的3指标，已逐项对照原evaluation summary和10episode均值，一致。扫描图最终纵轴在所有方法画完后统一重算，所有曲线点完整显示。
5. 轨迹为真实q0加60个动作后位置，共61点；边缘留少量显示边距，防止起点圆圈被图边缘截断，地图范围和真实坐标不改。
6. UAV总能耗图使用3机计算+推进能量，单位kJ。每机可行判定独立于3机总能量；不能以总量小于36kJ替代逐机12000J判定。
7. 全局enabled与命令行方法选择同时作用于每类图；last选择、轨迹checkpoint组合、原始长尾与新种子元数据均有回归检查。
8. 目视检查了主场景奖励图、全部方法和混合方法柱状图、轨迹网格、独立实验总览与扫描图。输出包括可编辑SVG、矢量PDF、PNG、source CSV及文件hash。

统计边界：当前仅1个训练种子。10个配对场景反映该已训练模型的场景变化，不是10次独立训练。数据尺寸、CPU、带宽、用户数变化属于参数敏感性分析，不能代替算法组件消融。不能因图形效果而删减异常数据或修改评估协议。

使用nature-figure流程记录图的目的、数据出处、统计口径与视觉核验；后端沿用Python/matplotlib。新定稿的`MANIFEST.json`和图表`manifest.json`记录文件SHA256，`tools/verify_plot_release.py --full-data`可再次核验。
