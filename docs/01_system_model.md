# 系统模型与实际执行语义

## 1. 场景

20个移动用户、3架固定高度UAV、1颗LEO卫星；每个任务整体选择本地、三架UAV之一或卫星。没有LUAV，也没有UAV到卫星双跳。

每个episode为60个1秒时隙，区域1000×1000m。用户初始均匀分布在中心(500,500)周围的500×500m正方形内；UAV从区域内切圆的三个等分点起飞。用户使用Gauss–Markov移动：速度/方向记忆系数0.6/0.9，每用户速度均值U[0,1]m/s，速度噪声方差2，方向噪声标准差2rad。负速度保留并直接参与位移，位置到地图边缘后反射。

UAV高度50m、最大速度20m/s、安全间距50m。CPU：每用户1GHz、每UAV10GHz、卫星50GHz。带宽：**每UAV独立10MHz**、卫星100MHz。每槽每用户生成一个0.5–2Mbit任务，计算密度1000cycles/bit；截止时间独立U[0.5,2]s，优先级为w_i=1/d_i。数据单位是Mbit，不是MB。

## 2. 槽首服务时序

槽首用户位置、UAV位置、任务和块信道确定后，先按累计能耗确定服务可用节点，再进行卸载和资源分配。当前速度只决定本槽推进能耗和下一槽位置，不能免费使用移动后位置处理当前任务。所有方法均采用同一时序。

每批任务独立计算完成时间。T_i可以超过1秒，不维护跨批排队、剩余上传和跨槽CPU占用；期限与d_i比较。代码保留真实超期任务，不丢弃、不记零时延。60秒episode是决策周期，不表示所有超期任务都在60秒内真实完成。

## 3. 信道与时延

固定用户发射总功率p=0.2W。给远端任务分配带宽b时，速率为

\[
R_{ij}(b)=b\log_2(1+\rho_{ij}/b).
\]

地面–UAV的ρ=pg/N₀；−114dBm表示1MHz参考带宽内总噪声，等效密度−174dBm/Hz，再计7dB接收噪声系数。UAV链路采用仰角相关LoS/NLoS概率、自由空间损耗及1/20dB附加损耗，LoS Rician K=6dB、NLoS Rayleigh小尺度衰落。

卫星轨道高度600km，最低服务仰角20°，S波段2GHz；使用自由空间损耗、3dB附加损耗、城市S波段仰角相关LoS概率/NLoS杂波损耗、LoS/NLoS阴影标准差4/6dB及Rician/Rayleigh衰落。卫星ρ由EIRP、G/T=1.1dB/K及C/N₀预算得到。具体表格和最近参考仰角选择在 `priority_mec/physics.py`。

这是室外城市有效块信道代理，不是废墟实测模型；1秒有效块和100MHz资源池不代表物理信道在全带宽、整个1秒内严格不变。

令C_i=1000D_i。执行时间为

\[
T_i^{local}=C_i/F_i^{local},\qquad
T_i^{remote}=D_i/R_{ij}(b_i)+C_i/f_i+\delta_{ij}.
\]

代码对UAV设置δ=0，对卫星设置δ=2r/c；忽略结果回传数据量及其占用资源，没有另外添加固定卫星等待时间。卫星仰角不足时链路不可用。若资源无效导致计算时延非有限，代码保留无效掩码/原始失败证据，并以100d_i作为明确失败代理计入奖励；有限但很大的真实时延不被截断。

## 4. 目标与约束

目标是最小化优先级加权时延和。日志采用固定用户数归一化：

\[
J_t=\frac1{20}\sum_iw_iT_i=\frac1{20}\sum_iT_i/d_i.
\]

J无量纲；`mean_delay_s`才是以秒为单位的平均时延。除以固定20不改变单独时延目标的最优解。系统还考虑单任务整体卸载、各节点带宽和CPU总量、期限、速度、边界、安全距离和每机累计能量预算。

给定关联的资源子问题尝试满足每个任务T_i≤d_i。关联可行修复失败时不宣称全局不可行；保留返回的实际分配、真实超期和失败状态。强化学习与均分基线不具备期限硬保证。详细证书与有限扫描限制见方法文档。

## 5. UAV能量与停服

UAV计算能量为κΣC_i，κ=10⁻⁹J/cycle，只计卸载到本机的任务。推进能量为P(‖v‖)Δt，包含悬停：

\[
P(v)=79.86(1+3v^2/120^2)+88.63+
\tfrac12(0.6)(1.225)(0.05)(0.5)v^3.
\]

该单调速度近似满足P(0)=168.49W，悬停60秒约10109.4J；不另计加速度和转弯能耗。UAV总能量含计算与推进，用户/卫星能量不计入UAV预算。

默认启用能耗触发停服。每架机槽首累计总能耗达到12000J后，本回合不再接新计算任务；若本槽末跨过阈值，下槽才生效。本槽已分配任务仍计时延和计算能量。停服后飞行继续、推进能量继续、历史能耗不清零，reset新episode重新开放。所有方法都排除已停服UAV，本地与可用卫星继续可选。

**停服不是硬电池容量保证。** 最终能量可行要求每架UAV分别≤12000J；三机总和不能与单机预算比较。最后一槽末超预算可导致能量不可行，却没有后续槽出现停服记录。

## 6. 奖励和安全处理

\[
r_t=-5J_t-\overline{(T_i/d_i-1)_+}
-2H\,\overline{(E_j(t+1)/B-1)_+-(E_j(t)/B-1)_+}
-5I_c-2I_b-p_{invalid},\quad H=60,\ B=12000.
\]

能量罚按超限增量计，避免每槽重复对历史超限收全额罚。I_c、I_b为请求碰撞/越界指示；先对请求动作计风险，再限速、边界修正及必要的防撞QCQP投影。投影失败回退安全零速度并报告。没有中心距离奖励、没有按剩余电量预先限速，也没有为投影消除原请求罚项。

总回报是60槽r之和；`penalty_sum = -episode_return - 60×5×weighted_delay_mean`。停服不另加一项罚款，原超能耗处罚继续保留。
