# 系统模型

本项目沿用当前优先级 UAV/LEO 场景。默认参数集中在 `configs/environment.json`，每次运行保存实际生效副本。新实验不读取旧项目配置或结果。

## 场景与时序

20 个移动用户、3 架固定高度 UAV、1 颗 LEO。每个任务整体选择本地、三架 UAV 之一、卫星；没有 LUAV，没有 UAV→卫星双跳。

| 项目 | 默认值 |
|---|---|
| 区域、时隙、episode | 1000×1000 m，1 s，60 时隙 |
| 用户初始位置 | 中心 (500,500) 周围 ±100 m 正方形内均匀采样 |
| 用户移动 | 高斯–马尔可夫；速度/方向记忆系数 0.6/0.9 |
| 移动均值与噪声 | 每用户速度均值 U[0,1] m/s；速度噪声方差 2；方向噪声标准差 2 rad |
| UAV 初始位置 | 地图内切圆上三个等分点，第一架 (1000,500) |
| UAV 高度/最大速度/安全间距 | 50 m / 20 m/s / 50 m |
| 本地/UAV/卫星 CPU | 1 / 每架10 / 50 GHz |
| UAV/卫星带宽 | **每架10 MHz** / 100 MHz，节点资源池相互独立 |
| 卫星高度/最低仰角 | 600 km / 20° |
| 数据量/计算密度 | 0.5–2 **Mbit** / 500 cycles/bit |
| 每任务截止时间 | 每槽独立均匀 U[0.5,2] s |
| 优先级 | w_i=1/d_i |
| 用户发射功率 | 0.2 W，固定总功率 |
| 单架 UAV 电池预算 | 整个60 s的计算＋全部推进能量 ≤12000 J |

负用户速度保持有符号，直接参与位置更新；方向不强行取绝对值。用户出界位置反射回地图。模型不把“1 m/s”当成严格移动速度。

每槽服务使用**槽首位置和信道**。当前任务与关联/资源决策产生 T_i(t)；当前速度 v_j(t) 消耗本槽推进能量并决定下一槽位置。贪心算法也遵守这一时序，不能免费用移动后信道服务本槽。

每秒生成一批任务，但本版是每批任务的独立完成时间模型：T_i 可超过1 s，只与其 d_i 比较；不维护跨批队列和下一槽剩余资源占用。这是现有仿真的明确范围，不应将结果解释为已验证跨槽排队稳定性。

## 通信与完成时间

固定发射总功率下，上行速率为

\[
R_{ij}(b)=b\log_2(1+\rho_{ij}/b),\quad
\rho_{ij}=p_i g_{ij}/N_0.
\]

本地执行 T_i=C_i/F_i^loc。远端节点执行

\[
T_i=D_i/R_{ij}(b_i)+C_i/f_i+\delta_{ij},\qquad C_i=500D_i.
\]

δ 包括模型中的传播时间。结果回传数据量忽略；没有额外人工固定卫星高时延。卫星仰角不足时不可用。

噪声 −114 dBm 指 **1 MHz 参考带宽内总噪声**，等效密度 −174 dBm/Hz，再按实际带宽与7 dB噪声系数计算。不是 −114 dBm/Hz。

地面–UAV：仰角相关 LoS/NLoS 混合大尺度损耗（a=9.61、b=0.16，额外损耗1/20 dB），块衰落；LoS 用6 dB K因子的 Rician，NLoS 用 Rayleigh。

卫星：自由空间传播损耗、3 dB附加损耗、城市S波段仰角相关 LoS/NLoS 概率及杂波损耗、LoS/NLoS 阴影标准差4/6 dB、LoS Rician/NLoS Rayleigh 小尺度功率，以及轨道位置/仰角变化。表格代理及实现见 `priority_mec/physics.py`。这是室外城市有效块信道代理，并非废墟实测模型，也不是100 MHz全带宽频率选择性波形仿真。

## 优化目标、资源与安全约束

目标最小化所有任务的优先级加权时延总和。代码记录

\[
J_t=\frac1{20}\sum_iw_iT_i=\frac1{20}\sum_iT_i/d_i.
\]

除以20是固定归一化，不改变单独时延目标的最优解。`weighted_delay_sum_per_frame` 是未除20的成本，`mean_delay_s` 才是以秒计的平均时延，不能混用。

约束包含单任务整体卸载、各节点带宽/CPU总量、每任务 T_i≤d_i、UAV速度/边界/连续槽内安全间距，以及每机累计能耗≤预算。实际无法满足期限时记录真实超期并罚款；不会丢任务或伪造按期完成。数值无效资源分配另记录无效率并用显式失败时延代理，不记为0时延。

## 能耗与奖励

UAV计算能量为 κ∑C_i，κ=10^-9 J/cycle，仅计该机接收任务。推进能量是 P(‖v‖)Δt，包含悬停；当前沿用单调速度功率近似：

\[
P(v)=79.86(1+3v^2/120^2)+88.63+
\tfrac12(0.6)(1.225)(0.05)(0.5)v^3.
\]

P(0)=168.49 W，单机仅悬停60 s需10109.4 J。不计额外加速度/转弯能耗；不能将这个近似模型的节能结果直接等同真实飞行节能。用户/卫星能耗不计入UAV预算，也不进入资源求解器。

保留原奖励，不新增朝中心移动奖励：

\[
r_t=-J_t-\lambda_d\overline{(T_i/d_i-1)_+}
-\lambda_E H\overline{(E_j(t+1)/B-1)_+-(E_j(t)/B-1)_+}
-\lambda_c I_c-\lambda_b I_b-\lambda_a p_{invalid}.
\]

默认 λ_d=1、λ_E=2、λ_c=5、λ_b=2、λ_a=1。能量项按增量超限计罚，整回合可望远镜求和；不是每槽对已累计超限重复收全额罚。

请求动作越界/碰撞照常罚。执行动作先限速、边界修正，并以凸QCQP处理需要修正的防撞冲突；失败回退安全零速度并报告。没有新加“先按剩余电池屏蔽动作且免除罚项”的协议。
